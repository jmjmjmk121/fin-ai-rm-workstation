Portfolio mathematics

สมการเชื่อมกันอย่างไร

  1. ผลตอบแทนพอร์ต: E[Rₚ] = wᵀμ
  2. ความแปรปรวน: Var(Rₚ) = wᵀΣw
  3. Frontier: ลด wᵀΣw ภายใต้ wᵀμ = r*, 1ᵀw = 1 และ w ≥ 0
  4. Stress: ผลกระทบทันที = wᵀs และขาดทุนเงินบาท = AUM × max(0, −wᵀs)
  5. Goal paths: ใช้เงินใน goal bucket, เงินเติมต่อปี, μ และ Σ ชุดเดียวกัน แล้วจำลองรายเดือน 5,000 เส้นทาง

Model boundaries

สิ่งที่โมเดลนี้ไม่กล่าวเกินจริง

  • Scenario shock คือเหตุการณ์รุนแรงแบบมีเงื่อนไข; lognormal projection หลังเหตุการณ์ไม่ใช่ fat-tail distribution
  • P5–P95 คือช่วงผลลัพธ์กึ่งกลาง 90% ไม่ใช่ confidence interval ของค่าประมาณ
  • SET SMART close ใช้เป็น market proxy ไม่ใช่ NAV ของกองทุนรวม
  • LLM เรียกเครื่องมือคำนวณและร่างภาษา แต่เลขมาจาก deterministic quant engine ที่ตรวจซ้ำได้
  • ไม่มี auto-send หรือ auto-trade; ลูกค้า, RM และ maker-checker ยังอยู่ในวงอนุมัติ
